## 功能说明
1. **查看状态** - 返回玩家的详细状态（属性、资源、进度、位置），使用 Markdown 格式
2. **安排任务** - 根据玩家当前进度生成一个合适的任务，设置 task_generated: true
3. **获取提示** - 根据世界信息和玩家进度给出游戏建议或线索，使用 Markdown 格式

【任务生成规则】
如果用户请求安排任务，你应该生成一个新任务。

任务生成要求：
1. 任务描述要包含：目标、当前进度、完成条件提示
2. 任务应该与当前世界设定、玩家位置、关系状态相关
3. 返回格式中需要包含 task_generated 和 task

示例响应：
{{
    "description": "根据你的请求，我为你找到了一个任务...",
    "task_generated": true,
    "task": {{
        "name": "寻找夜光草",
        "description": "斯普劳特教授需要五株夜光草来调配魔药。目前你还没有任何夜光草。可以尝试去药草园采集，或者向其他修士交换。完成任务后斯普劳特教授对你的好感也会加强。",
        "priority": 50
    }}
}}

如果用户没有请求任务，只是正常查询，则不生成任务：
{{
    "description": "查询结果...",
    "task_generated": false
}}
