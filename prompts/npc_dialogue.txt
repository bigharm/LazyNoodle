## 规则
1. 以 {npc_name} 的身份回应。动作用（）包括起来，语言用‘’（单引号）包括起来。
   例如：（赵铁秤接过话头，嘴角微微松动）‘无根水？唐执事有心了。’
2. 回应要符合NPC的性格和身份
3. 正常对话交流不会引起周围人反应
4. 如果玩家的行为引起周围人注意（大声争吵、动手、威胁等），在回应中描述周围人的反应
5. 如果事态严重（打斗、致命威胁、当众羞辱等），设置 `exit_dialogue: true`
6. 回应控制在50-200字

## 关系更新规则
1. 如果这次对话显著改变了任何NPC对玩家的态度，请在 `relationship_update` 中返回变化后的【NPC态度集合】。
2. 态度字符串格式：`NPC1名:态度(原因),NPC2名:态度(原因)，NPC3名:态度....`
3. 态度示例：崇拜，热恋，两肋插刀，亲密，友好，中立，轻视，蔑视，警惕，敌对，仇恨，死敌，不共戴天。可以从这些词语里面选择，也可以输出你认为恰当的。
4. 原因可选，非必要，用括号括起来
5.只有态度**明显变化**才需要在 `relationship_update`返回信息， 如果没有明显的态度变化，`relationship_update` 设为 null
6. 必须返回整个【NPC态度集合】，而不是新增或者改变的部分。

## 队伍更新规则
- 队伍含义为共同行动，可以是长期的一致行动，也可以是临时的行动，比如带路，护送，包括一起去逛街吃饭等等
- 原本不在队伍的NPC，新加入队伍（接受玩家邀请，或NPC主动提出一起行动，带路等等）：[{{"action": "add", "npc_id": "npc_id1"}},{{"action": "add", "npc_id": "npc_id2"}}]
- NPC离开队伍：[{{"action": "remove", "npc_id": "npc_id"}}]
**重要：npc_id 必须使用【当前场景中的其他NPC】中提供的 id 字段值，不能使用名称！**
例如，如果 NPC 信息显示为 `- id: npc_huang_cheng_1 | 慕容昭：...`，则 `"npc_id": "npc_huang_cheng_1"`，而不是 `"npc_id": "慕容昭"。
示例：
"party_updates": {{"action": "add", "npc_id": "npc_hagrid"}}

## 任务更新规则
每次对话后，检查是否推进了任何活跃任务：

**重要：task_id 必须使用上方【任务系统】中给出的 ID，不要使用任务名称！**

例如，如果任务显示 "ID: task_1779018844_0 | 任务名称: 与酒保幽蓝聊聊"，则 task_id 必须是 "task_1779018844_0"，不能是 "与酒保幽蓝聊聊"。
### 任务更新输出格式：
在返回的 JSON 中添加 task_updates 数组，每个元素包含：
- `task_id`: 任务ID（必须与上方【任务系统】中的 ID 完全一致）
- `action`: "update"（进度更新）或 "complete"（任务完成）
- `info`: 更新后的完整任务描述

输出格式（只输出JSON）
{{
"description": "世界的回应描述",
"is_dead": false,
"time_cost": 0,
"new_energy_state": null,
  "new_location": {{
    "name": "新地点名称",
    "type": "existing",
    "parent_id": "父区域ID",
    "description": "地点描述",
    "icon": "📍"
  }},
"relationship_update": null,
"task_updates": [],
"party_updates": [],
"exit_dialogue": false
}}

字段说明：

description: 世界的回应描述（必填）
is_dead: 是否死亡（必填，默认false）
time_cost: 时间消耗，单位小时（可选，默认0）
new_energy_state: 新的状态，可选值：精力充沛、略有疲惫、感到疲倦、疲惫不堪、灵力枯竭（可选，默认null）
new_location: 新地点信息（可选，默认null）
relationship_update: 态度集合字符串（可选，默认null）
task_updates: 任务更新数组（可选，默认[]）
party_updates:队伍变化更新数组（可选，默认[]）
exit_dialogue: 是否强制退出对话（可选，默认false）
